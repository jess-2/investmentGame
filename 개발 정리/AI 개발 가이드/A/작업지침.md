먼저 [공통 맥락](../00_공통_맥락.md), [연결 규약](../01_공통_연결_규약.md), [규칙 확정 기록](../02_결정_사항.md), [GitHub 지침](../03_GitHub_병합_지침.md)을 읽는다. 역할 데이터는 [임시데이터.json](./임시데이터.json), 기대 결과는 [통과기준.json](./통과기준.json)이다.

게임 손익 계산·코인 차감·정보 열람 판정·그래프 그리기는 A가 다시 구현하지 않는다. 요청 문맥과 통신을 담당하고 B/C 서비스를 호출한다.

## 권장 수정 범위

실제 프로젝트 생성 후 경로 예시: `Assets/Scripts/Network`, `Assets/Scripts/Flow`, `Assets/Tests/Network`, 접속용 Scene/Prefab. Shared·Unity 버전·패키지·공통 메인 Scene은 B/C/D 리뷰가 필요한 공통 변경이다. 다른 담당자의 규칙 코드를 편의를 위해 이 폴더로 복사하지 않는다.

## 입력과 출력

`임시데이터.json`의 `inputs`는 원본 파일 이름별 실제 데이터다. `sourcePath`는 작업공간 루트 기준 경로다.

- `A_room_initial.json`: 4명 연결·준비 완료, 1턴 INFO. 이미 연결된 상태를 주입하는 파일이며 연결 API의 구현을 대신하지 않는다.
- `A_selection_replay.json`: 요청 8개의 sender와 request만 추출한 재생 입력. 처음에 단계만 SELECTION으로 바꿔 재생한다.
- `exchange_examples.json`: 구매·주문 요청과 송신 대상의 설명. `senderPlayerId`를 실제 사용자 입력으로 믿지 않는다.
- `00_rules.json`: 시간·인원·기업·비중 단위.
- `referenceCases`: 원본 중 라우팅·차례·재전송·턴 지급과 연관된 사례의 `setup`과 `request`. 각 사례는 새 상태에서 실행한다.

반환 형식은 기존 요청/응답과 public update를 유지한다. 구매 결과 P1 단독, 자리 현황 전원, 정산 성과 전원으로 전송한다. 전체 시장·구매 원장·타인 주문을 공개 결과에 포함하지 않는다.

## 독립 개발 순서

1. 공통 DTO/서비스 선언을 단일 PR로 먼저 제안한다. 팀이 실제 사용 중인 선언이 있으면 재사용한다.
2. B/C 서비스의 동작을 흉내 내는 A 로컬 Mock을 주입해 요청·대상별 이벤트를 검증한다. Mock임을 명시한다.
3. 재전송 캐시는 방·플레이어·턴·요청 번호를 키로 한다. 같은 키·동일 payload는 기존 응답, 다른 payload는 합의된 오류로 거절한다.
4. 매 선택 성공 후에만 selectionIndex를 한 칸 증가시키고 8개 순서표의 다음 참가자를 결정한다. P4는 4·5번째 선택을 연속으로 한다.
5. B/C 실제 로직을 연결해 같은 입력에서 같은 결과가 나오는지 확인한다.
6. 로컬 멀티 인스턴스와 PC 4대에서 방장 자신의 요청을 포함해 왕복 검증한다.

## 반드시 통과할 데이터

- `통과기준.json.selectionResults.data.steps`의 8단계 결과와 `expectedSnapshots`의 최종 `D_public_after_selection.json`을 비교한다. AI·BIO의 잔석은 0, 나머지 기업은 1이다.
- 구매 요청 재전송 사례: 최초/재전송 응답 동일, 코인은 최종 2개, C의 구매 실행은 1회.
- wrong-phase/stale-turn/wrong-player 실패 시 B/C 상태 및 선택 차례가 변하지 않는다.
- `integrationChecks`는 실제 A 구현에 적용한다. 연결 신원 위조, 동시 요청, P1 단독 응답, 호스트 UI, 주문 잠금·정산 중복, 연결 종료 등의 실측이 필요하다.
- 예상 최종 공개 순위는 P1→P4→P2→P3이다. B가 계산한 결과를 전달하며 A에서 별도로 계산하지 않는다.

타이머가 manual인 JSON으로 실제 마감 판정이 완료됐다고 보고하지 않는다. 일반50/32/23/10/5초, 입찰턴15/35/32/23/10/5초로 검증한다. 참가자는30초 복귀 창을 제공하고 시계는 계속 진행한다. 호스트 이전·영구 복구는 구현하지 않는다.
