# A 다음 구현 결과와 B/C/D 인계

작성일: 2026-11-05. 기존 2026-11-02 현황 문서는 당시 기록으로 보존한다. 이번 변경은 A의 진행/전송/BOT과 이를 실행하는 데 필요한 B/C 연결 기반이다. 고유능력·아이템 전체 효과나 D의 전체 UI 개선 완료를 뜻하지 않는다.

## 실제 플레이 경로

`DevTabletBootstrap` → `SeededMarketProvider` + 실제 `MarketService`/`SharedInformationService` → `NetworkSession.Host` → 사람/BOT 각각 TCP + `GameClientController` → `GameRoom`.

- 시작 전 `ABILITY_SELECTION`에서 개인별 서로 다른 3후보 중 1개를 선택한다. 플레이어 간 중복은 허용한다. 전원 선택하면 진행하며, 방장은 완료로 미선택자에게 첫 후보를 적용할 수 있다.
- 능력 선택 시간은 기획 미확정이므로 기본 마감은 없다(`phaseEndsAtServerSeconds=0`). 서버 설정에 별도 `abilitySelectionSeconds`를 명시하면 독립 마감 후 기본 선택을 적용한다. INFO 시간을 사용하지 않는다.
- 일반 플레이 INFO 기본 90초, 선택 8×4초, 주문 23초, 공개 10초, 결과 5초다. 일반턴 최대 160초이며, 3·6·9턴만 입찰 15초를 앞에 더해 최대 175초다. 전원 완료 조기 진행은 유지한다.
- RESULT 뒤 1~9턴은 다음 턴을 시작하고, **10턴 정산·최종 승자 확정 후에만 종료**한다. 선택 인덱스/주문 잠금/완료 집합은 매 턴 초기화하며, 자산·코인·개인 기록·인벤토리·능력 상태를 유지한다.
- 시작 추첨은 1회이고 공개 `initialPlayerOrder`에 보존한다. 1~8턴 자리는 순환하며 9턴 입찰 배치를 10턴에도 사용한다.
- 기본 시장은 사인파/고정 fixture 대신 서버 seed와 턴으로 생성한다. 일일 폭 증가의 정수 경계는 `baseBps*(100+5*(turn-1))/100`의 정수 나눗셈이다. 각 턴은 캐시하고 복사본을 반환한다.

## Shared 및 B/C 연결

- `IProgressionService`는 C가 후보/선택·입찰·보상·개인 상태와 공개 이벤트를 소유하는 서버 계약이다. 실제 구현은 `SharedInformationService`의 `ProgressionService.cs` partial이다.
- `IMarketProgression`은 B의 턴 시작 S 조회/멱등 비용 확정/최종 승자 집계다. 기존 정산에 실제 비용을 전달하며 C가 별도 자산 잔액을 만들지 않는다.
- `SELECT_ABILITY`: 현재 turn 0, `payload.abilityId`. `SUBMIT_BID`: 현재 3/6/9턴, `payload.bidAmount`(long 정수), `useFreePass`, `seatPreferences`(A/B/C/D 순열). 잘못된 선호 배열은 기본 A/B/C/D다.
- 새 명령도 연결 신원·턴·단계·서버 수신시각·요청 키/지문·할당량 검사를 통과해야 한다. 같은 요청 재전송은 단계/마감 검사보다 먼저 원응답을 돌려준다. `bidAmount`는 소수·지수 표기·문자열·long 범위 초과를 wire에서 거절한다.
- `PlayerView`의 `ability/auction/inventory`는 본인에게만 전달한다. 공개 상태에는 시작 순서·자리 배치·난이도와 허용된 결과 이벤트만 넣는다. 비밀 입찰액·코인·타인 주문/구매목록은 넣지 않는다.
- 공개 이벤트는 안정된 `eventId`를 갖는 스냅샷 목록이다. D는 같은 ID를 다시 연출하지 않아야 한다. 입찰 이벤트에 금액을 추가하지 않는다.
- 새 DTO는 Unity 필드 직렬화와 .NET wire로 왕복하며 `DtoCopy`의 중첩 배열 복사도 갱신했다. 재접속은 능력 후보/선택·본인 입찰/인벤토리·최신 전광판, 공개/결과 단계 시장을 다시 전송한다.
- `GET_HISTORY`는 현재 턴 헤더와 `payload.historyTurn`으로 정산 완료된 과거 턴의 본인 정보/주문/자산·코인과 공개 전광판을 조회한다. 요청자 신원은 연결에서만 결정하며 타인 ID를 입력받지 않는다. 최종 종료 뒤에도 조회 가능하고 진행/마감/주문은 바꾸지 않는다. `HISTORY_VIEW`는 D의 별도 `Store.History`에 보관한다.

## D 연결 지점

- `DevTabletBootstrap.SetBotDifficulty(BotDifficulty)` 또는 호스트 전용 `NetworkSession.SetBotDifficulty("Easy"/"Normal"/"Hard")`. `LobbyActions`와 대기실 난이도 버튼은 D가 연결한다. 시작 이후 변경은 거절한다.
- `GameClientController.SelectAbility(id)`, `SubmitBid(amount, seatPreferences, useFreePass)`를 사용한다. 최소 연결 화면 `ProgressionPanel`을 제공했으며 기존 씬 파일은 수정하지 않았다. 전체 D 레퍼런스 UI를 대체하지 않는다.
- 과거 보기 버튼은 `GameClientController.GetHistory(turn)`과 `Store.History`에 연결한다. 과거뷰를 현재 `Store.View`로 덮어쓰지 않는다.
- 타이머는 기존 서버 마감 DTO와 `PhaseClock`을 사용한다. INFO 시작은 1:30이다. 능력 선택 기본은 시간 제한 없음으로 표시한다.
- `Scoreboard.gameComplete/winnerPlayerId`는 10턴 최종 결과다. 기존 턴별/누적 성과·추이는 유지한다.
