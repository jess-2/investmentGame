# 현재 구현 현황

확인일: 2026-11-02. 로컬 브랜치 `feat/network-game-lobby-bots`, HEAD `dff900a` 기준으로 실제 C# 코드와 검증 파일을 대조했다. 이 문서는 **구현 현황**이고, [다음 구현 계획](./05_다음_구현_계획.md)은 아직 구현하지 않은 작업이다.

## 현재 플레이할 수 있는 범위

Unity `6000.3.27f1`, uGUI, Unity Test Framework `1.6.0`을 사용한다. `Assets/Scenes/DevTabletUI.unity`에서 방 생성/참가 → 4명 준비 → 정보 구매 → 기업 2개 선택 → 비중·진입/청산 입력 → 주문 잠금 → 시장 공개 → 정산 → 종료까지 **1턴**이 연결되어 있다. 빈자리는 방장이 BOT으로 채우고 내보낼 수 있다.

현재 주 실행 경로는 다음과 같다. `LocalRoomHost`는 테스트용으로 남아 있지만 현재 게임 UI의 전송 방식은 TCP다.

```text
DevTabletBootstrap
  방장: MarketService + SharedInformationService → NetworkSession.Host
  사람/BOT: TCP 클라이언트 → GameClientController → GameRoom
  GameRoom → 실제 B/C 서비스 → 개인/공개 메시지 → ClientStateStore → TabletView
```

## 구현으로 오해하면 안 되는 부분

- `DevFixtures.Synthetic()`은 사인파 예제 시장이다. 정식 규칙의 일별 난수 증감·턴별 변동성 증가를 구현한 시장 생성기가 아니다. Editor는 고정 fixture, fixture가 없는 빌드는 이 예제 경로를 사용한다.
- B/C가 2턴 데이터를 보관하고 6턴 코인 규칙을 갖고 있어도 A의 게임은 1턴으로 종료된다. `ordersLocked`, `selectionIndex`, 완료 명단, 차례 순서와 새 시장 공급까지 연결해야 복수 턴이 된다.
- C의 ‘원본 불변성’은 반환된 복사본 수정이 서버 원본/다른 뷰에 전파되지 않는다는 뜻이다. 반환 객체 자체가 모두 수정 불가능하다는 뜻은 아니다.
- 기업 버튼 클릭은 즉시 `SELECT_COMPANY`를 전송하고 성공하면 다음 차례로 간다. 서버 확정 선택을 되돌리는 명령은 없다. 주문 초안의 구간 삭제는 이미 있지만 마우스로 날짜를 찍는 기능은 없다.
- 타인 선택은 `CompanySeat.remainingSeats`로 간접 표시한다. 공개 DTO에 기업별 참가자 명단은 없다. 이미지·자리 강조를 추가할 때도 이 공개 범위를 지킨다.
- 입찰·상점·능력·공격·최종 우승 판정은 기획 기록과 실제 구현을 구분한다. `Protocol`에 AUCTION 실행 흐름은 없고, 현재 `SettleTurn`은 비용 0으로 정산한다.
- 과거 기록은 서버 메모리 수명이다. 파일/DB 저장, 방장 종료 후 복원은 없다.

기본 fixture 정산 기대값은 P1 **14,280**, P4 **12,750**, P2 **11,080**, P3 **8,900**이다. 새로운 화면/BOT 테스트에서도 기준 주문을 직접 넣는 기존 회귀 사례는 유지한다. 새 BOT이 다른 주문을 만들면 그 결과를 위 금액으로 강제하지 않는다.

검사 시 `Assets/Scenes/DevTabletUI.unity`에 사용자 작업 변경이 있었다. 이번 요청은 가이드 작성이며 해당 씬·게임 C# 코드를 수정하지 않는다. `Logs`는 Git 제외이므로 다른 개발자는 같은 검사 명령으로 증거를 다시 만든다.

이전 A/C/B 통합 문서는 단계별 기록으로 보존한다. 최신 실행 경로는 [D의 TCP 연결 기록](./D/멀티플레이_UI_연결.md), 현재 전체 상태는 이 문서를 우선 읽는다.

가이드 검사 중 발견한 발표/요구사항 원문 경로도 현재 작업공간 구조에 맞췄다. `build_packages.py`는 프로젝트 또는 상위 작업공간의 원문을 찾고, 출처 스냅샷에 외부 파일을 `../` 경로로 기록한다. 관련 참고 문서에서는 깨진 원문 링크3개만 수정했으며 기본 fixture 수치와 역할 JSON의 내용은 변경하지 않았다.
