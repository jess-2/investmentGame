# 게임 규칙 확정 기록과 초기 밸런스

규칙 버전: `rules-v2`, 적용일: 2026-10-25. 문맥 패키지: `prototype-v2`.

- 수치는 플레이 테스트를 위해 임시로 **확정된 초기 설정값**이다.


## 2. 정보와 일별 거래: 사용자 확정

- 기업은 AI·SPACE·FOOD·BANK·BIO·AUTO 6개, 참가자는 4명, 전체 10턴이다.
- 한 턴의 시장은 0~30일차다. 0일차 기준값은 0%로 전원 공개한다.
- 정보는 **1~5일, 6~10일, 11~15일, 16~20일, 21~25일, 26~30일**의 6묶음이다.
- 묶음 하나를 보면 **각 날짜가 0일차 대비 몇 % 상승·하락했는지 5개 값을 모두** 알 수 있다. 전일 대비 값이나 묶음 평균이 아니다.
- 기업별 무료 2묶음은 방장이 한 번 추첨해 전원에게 동일하게 공개한다. 나머지는 1코인에 1묶음 구매한다.
- 진입·청산은 묶음 경계에 제한되지 않는 **정수 날짜**를 선택한다. `0 <= 진입일 < 청산일 <= 30`, `5 <= 청산일-진입일 <= 10`.
- 따라서 **3→8일(5일), 3→13일(10일)은 허용**, 3→7일(4일), 3→14일(11일), 26→31일은 거절한다. 소수 날짜도 거절한다.
- 미열람 날짜에도 거래를 걸 수 있다. 정보가 없다는 위험을 감수한 선택이다. 서버가 비공개 값으로 좋은 날짜를 추천하지 않는다.
- 기업마다 1~2개 구간을 사용한다. 중복·겹침은 금지하고 앞 청산일=다음 진입일은 허용한다.
- 두 구간은 같은 배정 원금에 구간 수익률 합을 적용한다. 구간 사이 원금은 현금 대기하며 중간 이익은 재투자하지 않는다.

## 3. 자산·코인·정산

| 항목 | 결정 |
|---|---|
| 시작 자산 | 10,000 게임머니. 외부 현금·과금과 무관 |
| 코인 지급 | 1~5턴 시작 시 3개, 6~10턴 시작 시 5개. 잔액 이월·상한 없음 |
| 구매 제한 | 정보 구매 횟수 상한 없음. 보유 코인과 남은 정보로 제한 |
| 재구매 | 무료/구매/아이템/훔치기로 이미 열람 가능한 묶음은 추가 구매 거절, 차감 없음 |
| 투자 | 서로 다른 기업2개, 기업당 최대2명, 5:5·6:4·7:3 |
| 비용 기준 S | 해당 턴 시작 직후의 자산. 그 턴 모든 상점 가격·입찰 상한의 고정 기준 |
| 투자 가능 자금 I | S에서 그 턴 확정 구매·입찰 비용을 뺀 금액 |
| 배분 | 첫 기업 원금=trunc(I×비중/10000), 둘째=I−첫 기업 원금. 잔돈 유실 없음 |
| 손익 | 기업 배정 원금×최종 기업 수익률/10000을 0 방향 버림 |
| 손실 하한 | 기업 최종 수익률은 최저 -100%. 공격 후 최종 자산도 최저0 |
| 파산 | 자산0은 파산 표시만 하고 탈락시키지 않음. 다음 턴 시작 시 1,000 재기 지원, 순위 자산에 포함 |
| 동점 순위 | 턴 중에는 공동순위. 정렬만 참가자 ID 사용 |
| 최종 승자 동점 | 최종자산 → 남은코인 → 최고 단일턴 수익률 → 시작 시 공개 추첨한 타이브레이크 순번 |

정산 공식은 실제 주가의 가격 비율이 아닌 게임의 차이 공식이다. -40%에서 +30%는 +70%다. 수익률 표시는 턴 시작 S 대비 자산 증감으로 계산해 구매·입찰 비용도 반영한다. 재기 지원은 지급된 다음 턴의 시작 자산에 먼저 포함하며 그 턴 투자 수익으로 세지 않는다. 누적 수익률은 게임 시작 10,000 대비 현재 자산 변화다. 지원을 받아도 부채나 추가 승점은 없다.

기업 최종 수익률 하한을 적용한 뒤 금액 손익을 계산한다. 재기 지원을 의도적으로 노리는 것보다 시작 원금을 지키는 편이 유리하도록 지원액은 초기 원금의 10%로 제한했다.

## 4. 최대 120초 턴과 자동 처리

| 단계 | 일반 턴 최대 | 3·6·9턴 최대 | 행동 |
|---|---:|---:|---|
| 시작 처리 | 0초 | 0초 | 지원·코인 지급, 시장 생성, 자리 배정 |
| 입찰 | 없음 | 15초 | 비밀 입찰 제출/확정 |
| 정보 탐색 | 50초 | 35초 | 구매, 정보형·공격형 아이템 |
| 기업 선택 | 32초 | 32초 | 8회×최대4초 |
| 투자 결정 | 23초 | 23초 | 비율·구간·금융형 아이템 확정 |
| 시장 공개 | 10초 | 10초 | 주문 잠금 후 공개·연출 |
| 결과 | 5초 | 5초 | 정산·순위·보상 |
| 합계 | 120초 | 120초 | 조기 완료 시 짧아질 수 있음 |

- 단계별 서버 마감시간을 사용한다. 사용하지 않은 시간을 다음 단계에 적립하지 않는다.
- 선택은 유효한 선택 성공 즉시 다음 차례로 진행한다. 각 차례에 새 4초를 준다. 나머지 단계는 전원 완료 시 조기 진행 가능하다.
- 마감 판정은 서버 수신 시각이다. 정확히 마감시각에 도착한 새 요청은 거절한다. 그 전에 처리된 동일 요청의 재전송은 캐시 응답만 돌려준다.
- 선택 시간 초과: 남은 자리 있고 본인이 고르지 않은 기업 중 **BANK→FOOD→AUTO→AI→SPACE→BIO** 순으로 하나를 자동 선택한다. 비공개 시장은 보지 않는다.
- 투자 미확정: 이미 확정한 주문은 유지, 미제출자는 선택 기업 순서대로 50:50·각 0→5일 1구간을 자동 확정한다. 클라이언트의 미전송 초안은 사용하지 않는다.
- 입찰 미제출은 0. 정보 미입력은 구매 없이 진행한다. 자동 선택·주문은 본인에게 자동 처리 표시를 한다.
- 코인 지급·자동 선택·정산은 중복 실행을 막는다. fixture의 수동 모드는 재현용 도구이며 실제 게임의 시간 초과 규칙이 없는 뜻이 아니다.

## 5. 1~8턴 자리 순환과 공개 범위

초기 플레이어 순서를 방 시작 시 추첨한다. fixture에서는 재현을 위해 P1,P2,P3,P4다. 첫4턴의 자리 A/B/C/D는 다음과 같고 5~8턴에 반복한다.

| 턴 | A | B | C | D |
|---|---|---|---|---|
| 1·5 | P1 | P2 | P3 | P4 |
| 2·6 | P2 | P3 | P4 | P1 |
| 3·7 | P3 | P4 | P1 | P2 |
| 4·8 | P4 | P1 | P2 | P3 |

선택은 자리 A→B→C→D→D→C→B→A. 9턴 시작 입찰에서 자리 A/B/C/D를 고르고 9·10턴 동일 배치를 사용한다.

참가자·현재 차례·기업별 남은 자리·무료 정보·성과는 공개한다. 타인의 구매 묶음·코인·투자금·구간·투자 기업 명단은 직접 공개하지 않는다. 차례와 잔석 변화로 기업을 추론하는 것은 허용된 심리전이다. “완전 익명 투자”라고 설명하지 않는다. 공격·능력 발동은 대상과 종류만 전광판에 알리고 비공개 정보 값은 넣지 않는다.

## 6. 입찰과 보상 분리

- **3턴 시작:** 블랙박스 분석권 1개를 비밀 최고가 입찰.
- **6턴 시작:** 블랙웨일 프리패스 1개를 비밀 최고가 입찰.
- **9턴 시작:** 9·10턴 투자 자리 선택 순위 입찰. 9턴 투자 전에 끝내 시간 역전을 없앤다.
- 입찰 범위는 0~floor(S×10%). 1게임머니 단위, 한 번 확정 후 변경 불가, 마감 전까지 타인 금액 비공개.
- 3·6턴은 낙찰자만 제시 금액을 지불한다. 모두0이면 유찰, 누구도 비용/아이템 없음.
- 동액은 시작 자산이 낮은 참가자 → 시작 추첨 타이브레이크 순번으로 결정한다. 상위권 자금만으로 항상 선점하지 않게 한다.
- 9턴은 유효 입찰액 순으로 A/B/C/D 중 원하는 자리를 하나씩 선택한다. **모두 자리를 얻으므로 각자 본인 입찰액을 지불**한다. 모두0이어도 위 동점 순서로 무료 배정한다.
- 프리패스는 9턴 입찰 시 사용 여부를 제출한다. 입찰액의 25%를 가산한 점수로 정렬하되 실제 비용은 원래 입찰액만 낸다. 환급·무조건 선점 효과는 없다. 정수 비교는 입찰액×125 대 일반입찰액×100으로 한다.
- 자리 선택은 입찰15초 안에 미리 제출한 A/B/C/D 선호 순서로 서버가 순차 배정한다. 미입력/잘못된 선호는 A→B→C→D. 추가4인 선택 시간을 붙이지 않는다.
- 별도로 3·6·9턴 **턴 수익률 단독 1위에게 보너스 코인1개**를 정산 뒤 지급한다. 수익률 동점1위라면 해당자 모두1개. 아이템 중복 지급은 없다.
- 구매·입찰 비용은 I에서 빠지므로 무료 순위 상승 수단이 아니다. 10턴에는 입찰을 다시 하지 않는다.

## 7. 아이템 초기 밸런스

상점 가격은 표의 비율×S를 0방향 버림하되 최소1게임머니. S=0이면 상점 구매 불가. 잔액 부족 시 거절한다. **상점 구매는 턴당1개**, 인벤토리 최대3개다. 낙찰·보상 아이템이 정원을 넘으면 그 아이템 대신 코인1개를 받는다. 사용한 아이템은 소모되고 쿨다운은 능력에만 있다.

턴당 금융형1개·정보형1개·공격형1개를 사용할 수 있다. 다른 턴에 산 것을 보관할 수 있다. 유효 대상에 사용을 확정하면 소모하며 결과 실패나 정치인 방어로 돌려주지 않는다. 잘못된 대상/단계/입력은 거절하고 소모하지 않는다.

| 아이템 | 분류·가격 | 확정 효과 |
|---|---|---|
| 증폭기 | 금융·S의3% | 선택한 본인 기업의 전체 구간 손익률×2. 이익·손실 모두 적용 |
| 하락 파쇄기 | 금융·4% | 선택한 본인 기업의 전체 구간 손익률 부호 반전. 상승이면 손실. 고정+150% 폐기 |
| 방패(리스크 헤지권) | 금융·2% | 선택 기업의 능력 배율 적용 후 수익률이 -3~+3%이면 +5%로 대체, -3% 미만이면 손실 절반, +3% 초과면 유지 |
| 대폭발 탐지기 | 금융·5% | 자기 주문의 1구간 지정. 그 구간 원본 변화율 차이 절대값이15% 이상이면 해당 기업 손익률에 +50%p, 미만이면 보너스0. +500% 폐기 |
| 블랙박스 분석권 | 정보·2% | 선택한 기업의 미열람1묶음 무료 공개. 대상 없으면 사용 거절 |
| 정보 왜곡 | 공격·2% | 대상이 유료로 구매한 묶음 중 서버가 무작위1개를 골라 표시를10초간 ???로 가림. 원본·정산은 불변. 임의 수치 입력 방식 폐기 |
| 정보 훔치기 | 공격·3% | 대상의 유료 구매 묶음 중 본인 미열람1개를 서버가 무작위로 복사. 무료/ITEM/STOLEN 정보는 복사 대상 아님 |
| 수익률 감소 | 공격·4% | 턴 시작 총자산 상위2명의 본인 외1명 지정. 정산 시 대상 I의10%를 차감. 한 대상에 이 아이템의 성공 효과는 턴당1회 |
| 블랙웨일 프리패스 | 특수·상점 없음 | 6턴 입찰로 획득, 9턴 입찰 점수25% 가산 후 소모 |

방패와 리스크 헤지권은 같은 아이템 ID SHIELD다. 금융형은 INVESTMENT에서 본인 선택 기업에 지정하고 주문 잠금과 함께 확정한다. 정보형·공격형은 INFO에서만 사용한다. 프리패스는 9턴 AUCTION에서만 사용한다. 정보 왜곡/훔치기는 유료 묶음이 없는 대상을 선택하면 거절하며, 공격자가 대상의 구매목록을 미리 열람하게 만들지 않는다. 가림 효과는 INFO 종료 시에도 해제된다.

## 8. 고유능력

시작 전에 각자 무작위3개 후보 중1개 선택한다. 플레이어 간 능력 중복을 허용한다. 미선택 시 제시된 첫 후보를 자동 선택한다.

| 능력 | 확정 효과 |
|---|---|
| 정치인 | 재사용 가능 상태에서 들어오는 첫 공격형 아이템 또는 기업사냥꾼의 감산을 자동 방어. t턴 방어 후 t+3턴 시작부터 재사용. 성공 시 공격 아이템3종 중 무작위1개 지급. 인벤토리 가득하면 코인1개 |
| 작전 세력 | 정보 훔치기1개를 들고 시작. 수익률 감소가 실제 차감시킨 금액의25%를 자기 수익으로 획득. 정보 훔치기 성공 시 다음 턴 첫 정보1묶음 무료 |
| 정보상 | 매 턴 첫 정보 구매1묶음 무료. 블랙박스 사용 시 같은 기업의 미열람 묶음을 선택 순서대로 최대2개 공개. 30일 전체 무료 효과는 사용하지 않음 |
| 기업사냥꾼 | 하락 파쇄기로 원본 하락 기업에서 양의 수익을 얻으면, 해당 기업에 함께 투자해 양의 손익을 낸 상대1명(이익 최대, 동점은 추첨순번)의 그 기업 수익을 배정원금의5%만큼 감산. 남아 있는 양의 기업손익까지만 차감하고 차감액50%를 획득. 적격자 없으면 추가효과 없음 |
| 도박사 | AI·SPACE·BIO의 투자 수익률/손실률×1.2. 증폭기와 합쳐2.4배. 대폭발 성공 보너스는 +60%p, 실패했다고 기본 손실배율을 면제하지 않음 |

정치인이 방패를 사용할 때 재사용 가능 턴을1 줄이되 현재턴보다 앞당기지 않는다. 정보상·작전세력의 무료 구매권은 이미 열람 가능한 묶음에 소비하지 않으며 다음 턴으로 누적하지 않는다. 동시 효과는 서버의 요청 처리 순서로 처리한다.

공격형 아이템의 정치인 방어는 INFO의 유효 사용 요청을 받을 때 판정하고 결과를 기록한다. 나중에 방패를 사용해도 이미 판정한 공격을 소급 변경하지 않는다. 기업사냥꾼 감산은 정산 시점의 방어 가능 상태로 검사한다. 무료 능력 열람은 ABILITY, 아이템 열람은 ITEM, 훔치기는 STOLEN 출처로 기록하며 실제 코인을 낸 PURCHASED만 유료정보 공격 대상이다.

## 9. 효과 적용 순서·상한

1. 턴 시작 지원/코인 지급 후 S 고정 → 입찰/상점 비용 차감 → I 산출.
2. 기업 원본 구간 수익률 합산 → 하락 파쇄기 부호 반전 → 도박사×1.2.
3. 증폭기×2 또는 방패 적용 또는 대폭발 보너스 가산. 금융형1개 제한으로 여러 금융형을 한 턴 중첩하지 않음.
4. 기업 수익률 최저-100% 적용 → 원금 배분·기업 손익 정수 계산.
5. 정치인 방어 여부를 반영해 수익률 감소 및 기업사냥꾼 감산 적용. 한 대상에 대한 두 종류의 감산 합은 최대 I의15%, 최종 자산을0 아래로 내리지 않음.
6. 실제 차감된 금액에 대해서만 작전세력25%·기업사냥꾼50% 보상 지급. 이 보상은 또 다른 감산·배율을 연쇄 발동시키지 않음.
7. 최종 자산·턴/누적 성과·순위 확정 → 3·6·9턴 성과 코인 보상.

정산 감산은 서버가 기록한 유효 요청 순서대로 적용하고, 기업사냥꾼의 수익자 판정은 각 기업의 금융효과 적용 후·공격 전 양의 손익 스냅샷을 기준으로 한다. 감산이 겹쳐도 이미 차감된 금액과15% 상한을 공유하며 남은 양의 기업손익·자산을 넘겨 가져가지 않는다. 기업사냥꾼 사용자가 여러 명이면 시작 추첨순번으로 처리한다. 중간 보상이 다음 감산 대상을 바꾸지 않도록 보상은 마지막에 일괄 반영한다.

금융형 없이 기본 테스트를 실행하면 기존 P1=14,280, P2=11,080, P3=8,900, P4=12,750 결과는 유지된다. 효과는 각 원금 또는 변화율 중 무엇에 적용하는지 위 순서를 따른다. 정치인 방어에 막힌 감산은 실제 차감0이므로 공격자 보상도0이다.

## 10. 시장 생성·과거 정보·연결 정책

- 실제 시장은 서버가 턴마다 새로 생성하고 그 턴에는 바꾸지 않는다. 구매/재접속으로 다시 생성하지 않는다. 고정 fixture는 수동 설계값이라 난수의 일별 증가 한계와 다를 수 있다.
- 초기 일별 무작위 증감 한계: BANK ±0.8%p, FOOD ±1.2%p, AUTO ±3.5%p, AI·SPACE ±8%p, BIO ±15%p. 각 정수 bps 범위에서 균등 추첨해 전일의 기준대비 값에 더한다.
- 0일차 대비 범위는 BANK ±6%, FOOD ±8%, AUTO ±20%, AI·SPACE ±50%, BIO ±80%로 clamp한다. 일별 증감 폭은 턴마다5%씩 증가(10턴1.45배)시키되 기준대비 범위는 유지한다.
- 코인/정보 열람 원장은 턴별로 분리한다. 지난 턴 결과와 본인 열람정보는 읽기 전용으로 보관하지만 이전 구매권으로 새 턴 정보를 열람하지 못한다.
- 호스트가 끊기면 게임 종료 안내. 호스트 이전/영구 서버 복구는 구현하지 않는다.
- 일반 참가자는 30초 안에 개인 재접속 토큰으로 복귀 가능. 게임 시계는 멈추지 않고 부재 중 위 기본 행동을 적용한다. 30초가 지나도 참가자 슬롯은 유지하며 해당 판은 자동 진행한다.
- 요청 캐시는 방 종료까지 유지한다. 같은 방/플레이어/턴/requestId+동일내용은 원응답 반환, 다른 내용은 REQUEST_ID_CONFLICT. 이미 완료한 동작을 다시 실행하지 않는다.
- 같은 턴/참가자의 새 요청은 최대256개로 제한하고 초과는 RATE_LIMITED. 정상 UI는 구매중 재클릭과 초단위 무한조회 방지.
- 위 내용은 통신·아이템 구현 기준이며 Python 검증이 실제 Unity 네트워크·게임 재미를 증명하지는 않는다.
