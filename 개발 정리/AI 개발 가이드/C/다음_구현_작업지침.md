# C 다음 구현: BOT 개인 정보 계약과 격리 검증

[현재 현황](../04_현재_구현_현황.md), [다음 계획](../05_다음_구현_계획.md), [검증](../06_다음_구현_검증.md), 공통 00~03과 실제 Information 코드를 읽는다. 코인 지급·구매·개인뷰·배열 복사는 이미 구현되어 있다. 새 BOT을 위해 구매 서비스를 복제하지 않는다.

## NEXT-C01: A가 사용할 구매/개인뷰 예제와 회귀

현재 경로는 `GameClientController.BuyInformation` → A → `SharedInformationService` → `InformationService`다. BOT도 같은 경로를 사용한다. C의 역할은 구매 대상 추천 AI가 아니라 권한·잔액·원장·응답의 정확성이다.

1. 본인 코인3개/공개2묶음 예제, 1묶음 구매 후 코인2개와 `PURCHASED` 추가 예제, 다른 플레이어는 그대로인 예제를 A에 제공한다. `startDay`와 5개 값의 인덱스 의미를 명시한다.
2. `ALREADY_VISIBLE`, `NOT_ENOUGH_COINS`, `MARKET_UNAVAILABLE`, 잘못된 턴/단계의 무변경 응답을 제공한다. A의 BOT은 실패를 받아 멈추거나 대체 행동을 해야 하며 C가 임의로 무료 구매를 허용하지 않는다.
3. 동일 requestId 재전송 시 같은 응답/1회 차감, 다른 내용이면 충돌, 서로 다른 요청의 잔액 경합도 검증한다. A의 직렬 처리와 C의 원자 처리 경계를 유지한다.
4. BOT 포함 개인뷰·구매 결과·에러에 미열람 원본/타인 구매 목록이 없는지 확인한다. BOT 전략에 `IMarketDataSource`를 넘기지 않는다.
5. 반환 묶음/응답/본인 주문 배열을 수정해도 원본·다른 플레이어·다음 조회가 변하지 않는지 기존 불변성 회귀를 유지한다.
6. 이전 턴 구매는 다음 턴 권한이 되지 않고 코인은 이월되며, 방을 나누면 같은 P1도 상태가 독립인지 확인한다. 90초 변경은 A가 담당하며 코인 지급량을 변경하지 않는다.

수정/검증 후보: `Assets/Tests/Rules/Information/{InformationServiceTests,SharedInformationServiceTests}.cs`, `Assets/Tests/Network/Editor/RealInformationValidation.cs`. 기존 서비스에서 결함이 발견될 때만 해당 구현을 수정한다.

통과 기준: **B01~B03, B06, R01~R02, G02**. 인계: A에 정상/실패 메시지와 실행 가능한 입력, D에 공개/구매/미열람 표시 의미. ‘새 API 필요 없음’도 인계에 명시한다.

## NEXT-C02: 차주 상점·인벤토리·전체 아이템

차주 기능으로 B의 비용 원장 계약을 먼저 연결한다. 턴 시작 자산 S·가격 최소1·상점 턴당1개·인벤토리3개·분류별 사용 제한을02대로 적용한다. 비용 차감·아이템 지급·효과 사용 기록이 부분 적용되지 않게 요청 키/검증/확정 순서를 정한다. C가 자산 잔액이나 손익을 복제하지 않는다.

증폭기의 기업 손익률×2 계산은 B, 구매/인벤토리/사용 원장은 C, 호출 시점·잠금은 A, 버튼/대기는 D다. 현재 없는 계약을 문서의 의사 메서드 이름만 보고 이미 구현된 API처럼 호출하지 않는다.

같은 원장을 하락 파쇄기·방패·대폭발 탐지기·블랙박스 분석권·정보 왜곡·정보 훔치기·수익률 감소·프리패스까지 확장한다. 유효 사용 시 소모/거절 시 무소모, 정보 출처 ABILITY/ITEM/STOLEN, 유료정보만 공격 대상, 가림10초/INFO종료 해제를 검증한다. 능력/보상 지급의 인벤토리 초과는 코인1개로 전환한다. 통과 기준: **N09~N10**.

## NEXT-C03: 차주3·6·9턴 입찰·보상

입찰 제출/확정/원장·비밀 금액·낙찰/동점·유찰·프리패스·자리 선호·보상은02를 따른다. 3·6턴은 낙찰자만 비용, 모두0이면 유찰이고9턴은 각자 실제 입찰액을 낸다. S의10% 상한·무입력0·동점 규칙·9/10턴 자리 배정을 검사한다. 3·6·9턴 정산 뒤 턴 수익률1위 보너스 코인도 별도 원장으로1회 지급한다. 통과 기준: **N04~N06**.

## NEXT-C04: 차주 고유능력5종

시작 전3후보/1선택·미선택 첫 후보·중복 능력 허용을 구현한다. 정치인·작전 세력·정보상·기업사냥꾼·도박사의 능력 상태, 초기 아이템, 무료권, 쿨다운/방어·정산 연계를02대로 기록한다. 무료권의 유효대상 검사·턴별 초기화·이월 금지, 정치인 재사용 t+3과 방패 단축, 정산 중 스냅샷/실제 감산 보상을 B와 검증한다. 통과 기준: **N07~N08**. 정보 기반 BOT에도 타인 구매목록 조회 API를 제공하지 않는다.
