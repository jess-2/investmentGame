# 하루 단위 정보·마우스 구간 편집·시가 진입

2026-11-09 조작 개정. 일별 정보·시가 진입은 v4를 유지하고 아래 예약 자동 적용·구간 제한 해제·주문 공개를 추가한다. 기존 고정 묶음 JSON과 종가 진입 fixture는 회귀 비교군으로 보존한다.

별도 미래 개편안은 [투자 유형·시장 이벤트 구현 계획](INVESTOR_TYPES_MARKET_EVENTS_PLAN.md)이다. 직업 개편과 거래일 고정 제안은 현재 게임에 적용하지 않았다.

## 2026-11-09 예약·구간·시장 공개 수정

- 파란 예약 띠는 **진입일 칸의 왼쪽부터 청산일 칸의 오른쪽까지** 표시한다. 양 끝에 `N일 시가`·`N일 종가`를 붙이고, 열람 가능한 체결 값 위치에도 표식을 그린다. 날짜 칸 중앙에서 띠를 자르지 않는다.
- 일반 게임은 보유 5~10일과 최대 2구간 제한을 해제한다. **1~30일의 같은 날 시가→종가 거래**, 0→30일 보유, 3개 이상 구간을 허용한다. 날짜 범위·역순·구간 중복 검사는 유지한다. 0→0일은 거래가 아니다. 같은 날 종가 청산/시가 재진입은 겹침이다.
- `예약하기`로 저장한 구간과 투자 화면에서 수정한 구간·비중은 `SAVE_TRADE_PLAN`으로 서버에 개인 저장한다. 정보 코인 소모·기업 선택·즉시 주문 잠금은 하지 않는다.
- 투자 마감에 **실제로 선택한 기업의 마지막 서버 저장 구간과 비중**으로 자동 주문한다. 미선택 기업의 예약은 거래하지 않는다. 구간이 없는 선택 기업만 기존 기본 0→5일을 사용한다. 비중 미설정은 50:50이다. `주문 확정`을 누르면 일찍 잠그며, 누르지 않아도 예약이 적용된다.
- 마감 전에는 수정·삭제 가능하고 재접속 개인뷰에서 예약을 복원한다. 턴 변경 시 초기화한다. 요청 재전송·실패는 원본을 중복 적용하거나 부분 변경하지 않는다.
- 구간 목록에 스크롤을 추가해 많은 구간도 편집·삭제할 수 있다.
- 시장 공개 이후에는 각 기업 그래프에 **플레이어 색 띠와 개별 레인**으로 확정 구간을 표시한다. 확대 목록에는 플레이어별 종목 합산과 모든 구간의 진입 시가→청산 종가 및 수익률을 표시한다. 수익률은 서버 정산식으로 계산한다. 종목 합산은 해당 기업 배분금 기준이며, 전체 자산 수익률과 구분한다.
- 타인의 구간은 전체 주문 잠금 전 공개하지 않는다. `MARKET_REVEAL.revealedMarket[].investments`에 공개용 플레이어 ID·구간·구간 수익률·종목 합산만 넣는다. 자산 배분 금액·개인 정보 구매 내역·예약은 공개하지 않는다.

아래 본문의 5~10일·2개 제한 및 별도 확정 필수 설명은 이 개정으로 대체한다. 정보 공개/구매의 날짜·코인 규칙과 구간 합산·비복리 정산식은 유지한다.

## 코인과 정보 구매

- 1~5턴 시작에 15코인, 6~10턴 시작에 25코인을 지급한다. 이월은 유지하고 같은 턴의 중복 지급은 없다.
- 개인 정보는 1~30일 안의 임의 연속 구간을 산다. 하루만 선택할 수도 있다. **새로 알게 되는 날짜당 1코인**이며 이미 공개·개인 열람한 날짜는 다시 차감하지 않는다.
- 선택 범위·신규 날짜 수·무료 적용·최종 비용을 구매 전에 표시한다. 마우스를 움직이거나 예약해도 코인을 쓰지 않는다. `정보 사기`를 누른 뒤 서버가 성공시켜야 코인과 정보가 바뀐다.
- 정보상은 매 턴 신규 날짜 5일까지 무료다. 여러 구매에 나누어 쓸 수 있다. 무료 일수가 부족하면 나머지 새 날짜만 코인으로 결제한다. 중복·잔액 부족·잘못된 범위·요청 재전송은 코인과 무료 일수를 중복 소모하지 않는다.
- 공용 공개는 기존처럼 4명이 5일씩, 차례당 최대 10초다. 블랙박스는 지정한 시작일에서 최대 5일을 연다. 30일 끝에서는 남은 날짜만 연다.

## 차트 조작

1. 차트에서 왼쪽 버튼으로 드래그해 시작일과 끝일을 고른다. 두 번 클릭해 양 끝을 고를 수도 있다. 슬라이더와 날짜 이동 화살표는 사용하지 않는다.
2. `정보 사기`는 선택 날짜를 개인 구매한다. `예약하기`는 구간을 서버에 개인 저장한다. 기업을 선택하면 해당 기업의 예약이 투자 초안으로 들어가고 마감 때 자동 주문된다. 예약만으로 기업 선택을 대신하지는 않는다.
3. 예약 구간을 누르면 선택된다. **몸통을 드래그하면 이동**, **양 끝을 드래그하면 진입일·청산일 조정**이다. 날짜·중복 검사를 통과한 편집만 저장된다. 실패한 드래그는 기존 예약을 유지한다.
4. 차트를 선택한 상태에서 **Backspace 또는 Delete**로 선택한 예약을 삭제한다. 텍스트 입력이나 다른 차트에 포커스가 있으면 영향을 주지 않는다. 삭제 버튼도 유지한다.
5. 우클릭은 그 날짜 하나를 새 정보 선택으로 지정한다. 예약과 겹치는 날짜도 하루만 따로 구매할 수 있다. 공개 단계의 선택은 항상 5일 창이다.
6. 투자 화면에서도 같은 드래그·예약·수정·삭제 방식을 쓴다. `주문 확정`은 조기 잠금이며 미확정 예약은 마감 때 자동 적용한다. 확정 이후·일시정지·단계 종료에는 편집하지 못한다.

## 진입 시가와 청산 종가

현재 모델은 갭이 없는 일별 경로이므로 `d일 시가 = (d−1)일 종가`다. 새로운 OHLC·고가·저가·갭을 생성하는 변경은 아니다.

```
구간 수익률(bps) = 청산일 종가 값 − 진입일 시가 값
종목 수익률 = 선택 구간 수익률의 합 (기존 최저 수익률 한도 적용)
```

- 구매한 날짜는 종가와 시가를 함께 받는다. 예를 들어 20일만 샀으면 20일 시가와 종가는 표시하지만 19일 봉은 미열람으로 유지한다. 다른 플레이어의 구매 날짜·값은 여전히 비공개다.
- 보유 기간은 실제 거래하는 양 끝 날짜를 포함해 센다. 예: **3일 시가→7일 종가 = 5일 보유**, **3일 시가→3일 종가 = 1일 보유**다. 일반 게임에는 5~10일 제한이 없다.
- 같은 날 종가 청산과 시가 재진입은 시간상 겹치므로 허용하지 않는다. 앞 구간이 7일 종가에 끝나면 다음 구간은 8일 시가부터 가능하다.
- 0일차는 기존 공개 기준값 0%로 남긴다. 기존 기본 주문·fixture의 0일 진입은 기준값을 사용한다.
- 수익률은 실제 가격 비율이나 복리가 아닌 기준 대비 bps 차이의 합이다. 봇도 허용된 시가·종가만 보고 같은 공식으로 비교한다.

## 통신·원장

- `BUY_INFORMATION_WINDOW`: `companyId`, `startDay`, **`endDay`**. 두 끝을 JSON 정수로 검증하고 요청 내용 지문에도 넣는다. 공개 선택은 여전히 연속 5일이다.
- `visibleWindows`와 구매 결과의 `dailyChangesBps`, **`dailyOpenBps`**는 요청 범위 길이와 같다. `paidCoins`는 실제 결제액이다. `PlayerView.entryAtOpen`으로 클라이언트·봇의 진입 기준을 동기화한다.
- 공용·개인·능력·아이템·훔치기의 원장은 임의 길이를 보존한다. 왜곡으로 다른 열람 근거가 사라지지 않으며, 훔친 기록은 다시 유료 원본으로 취급하지 않는다.
- 고정 fixture의 묶음 구매·3/5코인·종가 차이 기대값은 비교군에만 남긴다. 일반 실행은 새 규칙이다.
