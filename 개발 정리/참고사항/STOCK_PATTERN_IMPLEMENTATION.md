# 패턴 시장·정보 탐색 1차 구현

일반 게임은 [6턴 주식·증강 시스템](stock_game_system_design.md)으로 개편했다. 이 문서는 `feat/stock_pattern`에 보존한 패턴·구간 거래 버전의 기록이며, 패턴 실험실과 시장 생성 관련 내용은 계속 참고할 수 있다.

2026-11-09: [예약 자동 적용·구간 제한 해제·시장 공개 표시](DAILY_INFO_MOUSE_TRADING.md)를 추가했다. [투자 유형·공통 시장 이벤트 개편](INVESTOR_TYPES_MARKET_EVENTS_PLAN.md)은 별도 미구현 계획이다.

**현재 정보 구매·정산·차트 입력은 v4로 개정했다.** [하루 단위 정보·마우스 거래](DAILY_INFO_MOUSE_TRADING.md)를 먼저 읽는다. 아래 1차 구현의 5일 개인 구매·슬라이더·종가 진입 설명은 개정 이력이다. 현재는 신규 날짜당 1코인, 15/25코인 지급, 마우스 범위 선택/예약/수정/삭제, 시가 진입을 사용한다.

반영일: 2026-11-08. 기준: [STOCK_PATTERN_DESIGN.md](STOCK_PATTERN_DESIGN.md).

## 일반 게임에서 달라진 점

- `MarketService.CreateRandom`은 `PatternMarketGenerator`를 사용한다. Rectangle·DoubleTop·DoubleBottom·Flag 중 기업별 가중치로 하나를 선택한다. 완성/훼손/비패턴 생성 분기는 50/30/20이다. 이 수치는 게임 생성 비중이며 현실 통계나 수익 성공률이 아니다.
- 패턴 시작일·길이·진폭·기울기·비대칭·노이즈를 바꾼다. 제어점을 선형 보간하고 전체 진폭을 축소해 일별 한계와 누적 범위를 맞춘다. 재생성 루프가 없는 유한한 생성 방식이다. 0일차 0%, 종목별 기존 한계와 턴당 일일 한도 5% 증가는 유지한다.
- 턴 시작에 전체 차트를 고정하고 복사본으로 제공한다. 공개·구매·재접속 순서는 가격에 영향을 주지 않는다. 생성 분기와 시드는 서버 내부에만 있다.
- 기업당 무료 2묶음 대신 자리 순서대로 4명이 각각 5일을 공용 공개한다. 같은 기업은 허용하고 공용 날짜 중복은 금지한다. 4회가 끝나면 정확히 20개의 기업/날짜 값이 공개된다.
- 공개 차례는 최대 **10초**이며 INFO 예산 안에 포함된다. 네 명이 모두 시간을 사용하면 개인 탐색에 50초가 남는다. 짧은 검사 설정은 `min(10, INFO/5)`초를 사용한다. 시간 초과·연결 이탈 시 공용 정보가 적은 기업부터 고정 기업 순서, 시작일 오름차순으로 자동 선택한다. 숨은 값은 참조하지 않는다.
- 개인 구매는 시작일 1~26의 연속 5일, 1코인이다. 부분 중복은 허용하고 신규 날짜가 없는 창은 비용·무료권 소모 없이 거절한다. 코인 지급 3/5개, 투자 구간·보유 기간·비중·정산 공식은 그대로다.

## 화면 조작

1. 정보 구매 화면에서 기업 차트를 클릭하거나 슬라이더/화살표로 5일 창을 이동한다.
2. 버튼의 `시작~끝일 / 새 정보 N일 / 공용 공개·무료 구매·1코인 구매`를 확인하고 확정한다. 이동만으로는 공개하거나 차감하지 않는다.
3. 확대 화면에서도 동일하게 구매한다. 상단의 모드 버튼으로 정보 위치 선택과 개인 거래 계획을 전환한다. 공용 공개 중에는 정보 선택 모드로 고정한다.
4. 공개 기록에 선택자·구간·자동 선택 여부가 표시된다. 재접속해도 현재 공개 차례와 마감을 복구한다.
5. 확대 패널은 오른쪽 타이머 열과 상단 메뉴를 비워 둔다. 확대 중에도 공용 차례/단계의 남은 시간과 완료 버튼이 보인다.
6. 본인 공용 차례에는 파란 화면 테두리와 큰 상단의 `지금 내 차례입니다!`를 차례 종료까지 유지한다. 본인 차례가 오면 정보 화면으로 이동한다. 다른 사람 차례에는 선택자 안내로 바뀐다.
7. 투자 기업 선택은 카드 클릭 즉시 서버에 제출한다. 별도의 후보·선택 확정 버튼은 없다. 중복 요청·정원 마감·차례 밖·마감 후 클릭은 계속 차단하고 서버 응답으로만 선택 상태를 확정한다.
8. 접속 화면과 대기실의 작은 BOT 사용 안내 문구를 제거했다. 접속 주소와 오류·진행 상태 표시는 유지한다.

## 정보·아이템 원장

- 공용/개인/능력/아이템/훔치기 기록을 독립적으로 보존하고 일별 열람 여부는 합집합으로 계산한다. 개인 응답에는 허용 날짜만 포함한다. Y축은 공개된 종목별 한도를 사용한다.
- 정보상의 무료 구매권은 유효 구매에서만 소모된다. 블랙박스는 선택한 5일 창을 열며 정보상은 첫 창 이후 남은 미열람 날짜를 기준으로 추가 창을 연다.
- 정보 훔치기는 상대의 실제 유료 기록 중 새 날짜를 주는 기록만 복사한다. 복사 결과는 STOLEN이며 재탈취 원본이 아니다.
- 왜곡은 상대 유료 기록 하나의 열람 근거를 서버 게임 시간 10초간 가린다. 같은 날짜를 공개·다른 구매 등으로 알면 계속 보인다. 효과를 적용할 날짜가 없으면 소모하지 않는다. 일시정지 중에는 만료 시간도 멈춘다.
- 정보 아이템은 공개 종료 후 확대 화면에서 사용한다. 기존 상점과 기타 금융·공격 능력 전체를 구현하는 작업은 이번 범위에 포함하지 않는다. 이미 지급되는 블랙박스·정보 훔치기를 연결하고 DISTORT 요청도 같은 원장 규칙을 사용한다.

## 계약과 비교군

`prototype-v3` / `rules-v3-windows`. 새 명령은 `REVEAL_INFORMATION_WINDOW`, `BUY_INFORMATION_WINDOW`, `USE_INFORMATION_ITEM`이다. `startDay`는 별도 필드이며 기존 `bundleIndex` 의미를 바꾸지 않는다. 상세 DTO는 `Assets/Scripts/Shared/Contracts.cs`, 인터페이스는 `Services.cs`를 따른다.

기존 `RandomMarketGenerator`, `SeededMarketProvider`, 고정 시장 생성자와 v2 JSON fixture는 비교·회귀 검사에 남겨 둔다. 일반 게임의 실행 경로는 새 생성기와 창 기반 정보 서비스를 사용한다. BOT도 새 공용 차례와 열람 가능한 날짜만 사용하며 투자·정산은 기존 서버 검증을 통과한다.

## 검증

- `.NET AValidation`: 기존 49개와 신규 5개 그룹, 총 **54개 통과**. 신규 그룹에는 4,800개 종목 경로의 재현성·일일/누적 한계와 모든 합법 보유 구간 조사, 공개 순서·중복·요청 재전송, 기한·이탈·재접속, 부분/전체 중복·무료권·아이템 원장 검사가 포함된다.
- 실제 TCP 10턴을 사람 스크립트 4명, 사람 2명+BOT 2명, 사람 1명+BOT 3명 조합으로 검증한다.
- Unity 확대 UI 검사는 타이머 영역과 확대 패널이 겹치지 않는지, 5일 창을 이동해도 명령이 전송되지 않는지, 확정 시 새 요청의 시작일이 전송되는지, 공개 차례 변경에도 확대·숨은 날짜 처리가 유지되는지 검사한다.
- 차례 UX 추가 수정 후 Unity 전체 EditMode **160/160 통과**. 실제 GPU로 UI 검사 6개를 포함해 실행했다. 10초 기한의 직전/정각, 공개 전체 40초, 일시정지·재접속, 상단 안내의 5초 이후 지속, 기업 카드 즉시 요청·중복/정원/기한/타인 차례 차단을 확인했다.
- 최신 검증 로그는 `Logs/TurnUx-results.xml`, `Logs/TurnUx-Unity.log`이며 화면은 검사 복사본의 `Logs/PlanningScreens/stock-window-*.png`, `public-my-turn-highlight-zoom.png`, `company-click-selection.png`에 저장한다.
- 검증 로그: `Logs/AValidation-results.json`, `Logs/StockPattern-results.xml`, `Logs/StockPattern-Unity.log` (Git 제외).

실제 여러 PC의 동시 접속과 플레이 만족도·패턴별 최적 수익 분포의 밸런스 조정은 별도 플레이 테스트가 필요하다. OHLC·갭·거래량·사전 뉴스·가변 길이 구매는 후속 설계대로 남긴다.
