# 증강 — 현재 구현 요약

기준: 2026-11-10, 현재 일반·개발자 플레이 코드. 화면 설명보다 실제 적용 수치를 기준으로 정리했다.

## 1. 선택 방식

- **1·3·5턴 시작에 3개 후보 중 1개**를 선택한다. 선택한 증강은 게임이 끝날 때까지 유지되어 최대 3개를 보유한다.
- 후보는 시드·턴·플레이어별로 무작위 선정하며, 이미 보유한 증강은 제외한다. 증강별 별도 가중치는 없다.
- 현재 후보로 등장하는 증강은 **11종**이다. ‘유연한 투자자’는 여러 기업 동시 주문이 기본 규칙이 되어 후보에서 제외했다.
- 일반 모드는 **20초** 안에 선택하지 않으면 첫 후보를 자동 선택한다. 집중 투자자 자동 선택 시 대상은 AI다. 개발자 모드는 시간 제한이 없다.

## 2. 증강별 효과

| 증강 | 현재 적용 효과 |
|---|---|
| 선점 투자자 | **게임당 1회**, 아직 시작하지 않은 내 매수 차례를 한 자리 앞당긴다. 현재 진행 중인 차례는 밀어내지 못한다. |
| 기회 포착 | 유효한 매수가 **시장 잔여 물량 부족**으로 실패하면 턴당 1회, 정보 **2일 할인**을 받고 다음 턴에도 2일 할인을 예약한다. |
| 내부 분석가 | **선택 즉시 2일 할인**, 이후 매 턴 시작에도 정보 2일 할인을 받는다. |
| 추세 추종 | 직전 턴 **28·29·30일에 매일 전날보다 오른 기업**의 이번 턴 **1~3일 정보**를 무료로 확인한다. |
| 바이오 연구원 | 이번 턴 BIO 이벤트의 성공 확률 **35~75%**를 확인한다. 성공 여부나 최종 수익을 확정해 주지는 않는다. |
| 우주 개척자 | SPACE의 연속 보유 판정이 **2턴 이상**이면 해당 기업 배분금에 **+2%** 보너스를 더한다. |
| 복리의 마법 | BANK에 예금된 금액과 기간을 반영해 **2%** 추가 이자를 지급한다. 최대치는 정보 비용 차감 후 투자 가능 자산의 **1%**다. |
| 위험 분산 | 정산 시 **각 3주 이상인 기업이 3곳 이상**이면 기업별 음수 수익률을 **80%로 줄여 손실 20% 완화**한다. |
| 장기 투자의 힘 | 같은 기업의 연속 보유 판정이 **3턴 이상**이면 해당 기업 배분금에 **+2%** 보너스를 더한다. |
| 하락장 사냥꾼 | 직전 턴 **30일차 가격이 0일차보다 낮은 기업**의 이번 턴 **1~3일 정보**를 무료로 확인한다. |
| 집중 투자자 | 선택한 기업 한 곳의 개인 보유 한도를 **10주 → 12주**로 높인다. BANK는 선택 불가하며, 기업 총 20주·개인 총 30칸 제한은 유지한다. |

## 3. 적용 시 알아둘 점

- **정보 할인:** 신규 날짜당 1코인을 대신하는 할인이다. 남은 할인은 여러 구매에 나눠 쓸 수 있다. 기회 포착·내부 분석가의 즉시 지급 시 보유 할인은 최대 4일이며, 다음 턴 시작에는 예약 할인과 내부 분석가 2일로 다시 설정된다.
- **보유 조건:** 매 턴 주식 수량은 초기화된다. 연속 보유는 다시 매수한 뒤 정산 시점까지 남아 있는 수량으로 이어가며, 구간 청산으로 해당 기업 수량이 0이 되면 연속 기록이 끊긴다. 위험 분산도 정산 시 남은 수량을 확인한다.
- **보너스 중첩:** 우주 개척자와 장기 투자의 힘의 조건을 함께 충족한 SPACE에는 총 **+4%**를 더한다. 보너스는 전체 자산이 아닌 해당 기업 배분금 기준이다.
- **BANK 구간:** 복리의 마법은 실제 BANK 예금 구간에만 적용된다. 구간 밖에서 현금으로 대기한 시간은 예금 기간에 포함하지 않는다.
