# 패턴 실험실과 자동 Y축

2026-11-08 반영. Unity 상단 **BlackWhale → 패턴 실험실**에서 연다. Scene 뷰 옆에 도킹되는 별도 EditorWindow이며 탭을 최대화하거나 분리할 수도 있다. 현재 씬을 교체하거나 Play 모드를 시작/종료하지 않는다. 일반 게임 방과도 연결되지 않는다.

## 실험실에서 볼 수 있는 것

- **패턴별 비교:** 선택한 기업에 대해 박스권·M자·W자·깃발형 각각의 완성 분기·실패/훼손 분기·비패턴 대조군, 총 12개 샘플을 모아 본다.
- **일반 게임 생성:** 실제 일반 게임과 같은 시드·턴으로 뽑힌 6개 기업의 차트를 본다. 기존 생성기를 그대로 사용하며 같은 입력이면 원본 시장과 날짜 값이 일치한다.
- 시드 직접 입력, 새 시드, 1~10턴, 비교할 기업을 선택한다. 종가선/캔들 전환과 주 패턴 배치 구간 강조를 지원한다.
- 카드를 누르면 해당 샘플을 큰 그래프로 보고, 상세 닫기로 목록으로 돌아간다.
- 분기 이름은 생성 조건을 뜻한다. 실험실에서 실제 형태를 살펴보기 위한 것이며 현실적인 성공률·수익을 보장하지 않는다. 비패턴 대조군에는 주 패턴을 넣지 않는다.

패턴 유형·분기·시드·배치 날짜는 이 개발용 창에만 표시한다. 게임의 `PublicState`, `PlayerView` 등 네트워크 DTO에는 추가하지 않았다. 실행 중인 방의 시드나 숨은 시장을 읽는 기능도 없다.

## Y축 변경

일반 게임의 종목 카드·확대 차트·투자 차트와 실험실에 같은 자동 맞춤 정책을 적용한다.

1. 현재 차트에 표시할 수 있는 **시가·종가와 공개 기준값 0**만 읽는다.
2. 그 값들의 최소·최대 범위에 여백을 두어 맞춘다. 일방향 움직임에서도 반대쪽 빈 공간을 크게 낭비하지 않는다.
3. 값이 없거나 모두 같은 경우에도 유효한 최소 표시 범위를 사용한다.
4. **Y축 상·하한 퍼센트와 기업별 최대 변동률 숫자는 표시하지 않는다.** 가로 보조선에도 수치를 붙이지 않는다. 날짜 축과 열람한 날짜의 가격 툴팁은 유지한다.

일반 게임은 전체 숨은 배열·숨은 고점/저점·기업 상한을 축 계산에 넣지 않는다. 따라서 비공개 값만 달라져도 열람 정보가 같으면 축과 그림은 같다. 정보를 추가 구매하면 새로 알게 된 값으로 범위가 조정되고, 전체 공개 이후에는 전체 값을 사용한다.

실험실은 샘플의 30일 전체가 공개된 환경이므로 전체 값에 맞춘다. 이 변경은 차트 표현만 바꾸며 생성기 가격 경로·거래 가능 날짜·코인·정산 공식은 변경하지 않는다.

## 관련 구현과 검증

- `PatternMarketGenerator.Inspect`: 기존 난수 흐름을 유지하는 독립 진단 샘플. 강제 패턴·분기는 실험실 비교용 인자다.
- `PatternLabWindow`: 메뉴와 12개 비교/6종목 보기, 선/캔들 표시.
- `ChartVerticalRange`: 현재 열람값만 받는 순수 Y축 계산. `BarChartGraphic`과 실험실이 공유한다.
- 검증은 일반 생성과 진단 샘플의 일치, 강제 12분기의 범위·일일 한도, 평탄/일방향/작은 변동의 자동 맞춤, 숨은 값과 종목 한도에 대한 축 불변성, 실험실을 열어도 씬이 유지되는지, 일반·확대 UI의 상·하한 퍼센트 제거를 포함한다.

로그: `Logs/AValidation-results.json`, `Logs/PatternLab-results.xml`, `Logs/PatternLab-Unity.log` (Git 제외).

검증 결과: .NET 58개, Unity EditMode 163개 모두 통과. 추가로 실험실의 실제 Repaint에서 카드가 그려지는지와 열람값 기반 축 계산을 다시 검사한 2개도 통과했다(`Logs/PatternLab-paint-results.xml`). 실행 중인 원본 Unity는 Console 탭도 갱신되지 않는 상태여서 원본 창의 육안 확인은 제한됐으며, 렌더링 검사는 격리된 Unity 프로젝트에서 수행했다.
